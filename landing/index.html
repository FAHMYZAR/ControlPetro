Keunggulan

Yang bikin ControlPetro beda.

Bukan sekadar daftar app. Ini kokpit server kamu: semua yang biasanya butuh banyak tab dan banyak klik, dikumpulin di satu tempat yang enak dipakai dari HP.

Unggulan

Terminal Termux

Terminal beneran, bukan kotak input. Ketik langsung di terminal, output ANSI berwarna ke-render, Ctrl+C beneran batalin proses. Tiap app punya terminalnya sendiri, plus Terminal Utama.

$ npm start
bot jalan di port 3101
$ ls -la
settings.js   src/   sessions/
Zoom 50 sampai 200 persenLayar Penuh buat fokusToolbar CTRL / ALT / ESC / TAB

File Manager

Baca, tulis, edit, hapus, rename, permission, upload 100 MB. Klik kartu app langsung masuk ke folder app itu.

Wizard 3 Langkah

Project, Instalasi dengan log live, lalu Deploy. App dibuat berhenti dulu, baru jalan setelah install beres.

Aplikasi

Start, Stop, Restart, Buka via proxy, Setup, Hapus. Status running atau stopped kelihatan sekilas.

Log

Log per app dan log gabungan. Kalau app error, ketahuan dari sini, bukan dari tebak-tebakan.

Keamanan

Login session-only, rate-limit 5 kali salah per 5 menit, cookie HttpOnly. Tanpa Basic Auth yang ke-cache di browser.

Tampilan

Satu layar untuk semua app.

Beranda nunjukin status semua app, RAM, disk, dan uptime dalam satu layar. Tidak perlu buka banyak tab buat tahu server kamu sehat atau tidak.

Cara Pakai

Dari project kosong
sampai app jalan.

01

Tambah App

Pilih sumber Git, Upload file, atau Kosong. Kasih nama, deskripsi, dan stack. App dibuat dalam keadaan berhenti.

02

Instalasi

ControlPetro deteksi dependency otomatis. Edit command kalau perlu, jalankan install, pantau log live sampai beres.

03

Deploy

Tentukan start command, port auto atau manual, dan env. Deploy dan jalankan. Build gagal, app tidak di-start.
